## Copyright Notice

All Umamusume: Pretty Derby character designs, card artwork, and game assets are © Cygames, Inc.

This directory is prepared for support card images. Currently using placeholder images for legal compliance.

## Image Guidelines

- **Placeholders**: Generic card back images by rarity (SSR, SR, R)
- **Future Integration**: Structure supports adding licensed images
- **Attribution**: All images must include proper copyright attribution
- **Fair Use**: If using actual card images, must comply with fair use guidelines

## Legal Compliance

This is a non-commercial, educational fan project not affiliated with or endorsed by Cygames, Inc.

If you are a copyright holder with concerns, please contact the project maintainer.

## File Naming Convention

- `placeholder_ssr.png` - SSR rarity placeholder
- `placeholder_sr.png` - SR rarity placeholder  
- `placeholder_r.png` - R rarity placeholder
- `card_back_generic.png` - Generic card back

Future licensed images should follow:

- `{character_slug}_{card_slug}.jpg`
- Example: `kitasan_black_fire_at_my_heels.jpg`
