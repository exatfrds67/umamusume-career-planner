# Skill System and SP Management

## Skill Point (SP) Basics

### SP Generation

- **Wit Training**: Primary source (+3-8 SP per session)
- **Training Events**: Random bonus (+5-20 SP)
- **Race Victories**: +15-30 SP based on race grade
- **Support Card Events**: Variable (+10-50 SP)
- **Skill Hints**: Reduce acquisition cost by 20-40%

### SP Budget Planning

- **Total SP Available**: ~1200-1800 across full career
- **Early Acquisition**: Skills learned early compound value
- **Cost Efficiency**: Prioritize hinted skills (reduced cost)
- **Strategic Timing**: Learn acceleration skills before big races

## Skill Categories

### Speed Skills

- **Acceleration**: Quick speed-up at race start or position changes
- **Sprint**: Final straight-line speed boost
- **Pace Control**: Maintain speed efficiently
- **Cost Range**: 120-180 SP
- **Best For**: Front runners, speed-focused builds

### Stamina Skills

- **Conserve Energy**: Reduce stamina consumption
- **Recovery**: Faster stamina regeneration
- **Endurance**: Extended high-speed maintenance
- **Cost Range**: 100-160 SP
- **Best For**: Long distance, late-game strategies

### Position Skills

- **Block Resistance**: Easier passing through traffic
- **Positioning**: Better lane placement
- **Overtake**: Bonus when passing opponents
- **Cost Range**: 110-170 SP
- **Best For**: Middle-pack, late surgers

### Activation Skills

- **Trigger-Based**: Activate on specific conditions
- **Always-On**: Passive constant benefits
- **Combo Skills**: Chain with other skills
- **Cost Range**: 80-200 SP
- **Best For**: Skill-heavy wit builds

### Unique Skills

- **Character-Specific**: Only available to certain characters
- **Event-Unlocked**: Require specific story events
- **Powerful Effects**: Often game-changing
- **Cost Range**: 150-240 SP
- **Best For**: Maximizing character strengths

## Skill Acquisition Strategy

### Priority Tiers

#### Tier 1 (Essential - Learn Early)

- Core acceleration skills for your strategy
- Stamina efficiency for race distance
- Basic positioning skills
- **Total Cost**: ~300-400 SP

#### Tier 2 (Important - Mid Game)

- Advanced acceleration variants
- Strategy-specific enhancements
- Synergistic combo skills
- **Total Cost**: ~400-600 SP

#### Tier 3 (Optional - Late Game)

- Luxury/polish skills
- Situational advantages
- Character unique skills
- **Total Cost**: ~300-500 SP

### Hint System Optimization

- **Hint Appearance**: Random during training with appropriate cards
- **Hint Duration**: 3-5 turns before expiration
- **Cost Reduction**: 20-40% SP discount
- **Strategic Delay**: Wait for hints on expensive skills
- **Multiple Hints**: Can stack multiple discounts

### SP Efficiency Guidelines

1. **Never buy full price when hint available** (unless urgent)
2. **Prioritize hinted skills** for maximum SP stretch
3. **Learn cheap skills early** for immediate benefit
4. **Save SP for late-game power skills** if build allows
5. **Avoid redundant skills** that don't stack

## Skill Synergies

### Acceleration Chains

- Multiple acceleration skills can combo
- **Example**: Start Dash → Mid-Speed → Final Sprint
- **Effect**: Smooth speed curve throughout race
- **SP Investment**: ~400-500 SP
- **Best For**: Front runners

### Stamina Preservation Combo

- Recovery + Conservation skills
- **Example**: Good Recovery → Stamina Keeper
- **Effect**: Extended high-speed running
- **SP Investment**: ~300-400 SP
- **Best For**: Long distance

### Position Control Suite

- Block resistance + passing skills
- **Example**: Escape Tactic → Quick Maneuver
- **Effect**: Optimal lane positioning
- **SP Investment**: ~350-450 SP
- **Best For**: Middle-pack strategies

### Wit-Based Activation Build

- Multiple conditional triggers
- **Example**: Trigger skills + Root or Lead
- **Effect**: Frequent activation bonuses
- **SP Investment**: ~500-700 SP
- **Best For**: High-wit builds

## Advanced SP Management

### Race Reward Optimization

- **G3 Races**: +15 SP
- **G2 Races**: +20 SP
- **G1 Races**: +25-30 SP
- **Special Races**: +30-50 SP
- **Strategy**: Balance training vs race participation for SP

### Event SP Maximization

- Build bond with skill-focused support cards
- Trigger training events frequently
- Prioritize events that offer SP or skill hints
- Maintain high mood for event frequency

### Late-Game SP Crunch

- Turns 60-72: Limited SP generation opportunities
- Must finalize skill loadout by turn 65-70
- Emergency SP sources: Health room events, final races
- Leave 100-200 SP buffer for unexpected opportunities

## Meta Skill Recommendations

### Current Meta (2024-2025)

- **Universal**: Acceleration III, Recovery I-II
- **Distance-Specific**: Stamina Keeper (long), Sprint Master (short)
- **Strategy**: Position Keep (chase), Lane Change (surge)
- **Wit Synergy**: Root skills, activation-based triggers

### Budget Builds (1200-1400 SP Total)

- 3-4 essential skills (Tier 1)
- 2-3 supporting skills (Tier 2)
- 1-2 polish skills (Tier 3)
- Focus on hinted acquisitions

### Premium Builds (1600-1800 SP Total)

- 5-6 core skills (Tier 1)
- 4-5 enhancement skills (Tier 2)
- 2-4 luxury skills (Tier 3)
- Can afford some full-price purchases

## Skill Learning Timing

### Optimal Windows

- **Turns 1-24**: Learn 1-2 core skills with hints
- **Turns 25-48**: Main skill acquisition phase (4-6 skills)
- **Turns 49-65**: Finalize loadout (2-3 remaining skills)
- **Turns 66+**: Emergency only, focus on race preparation

### Pre-Race Power Spikes

- Learn acceleration skills 1-2 turns before major races
- Immediate performance boost for upcoming competition
- Time learning around Classic/Senior goal races
- Balance skill timing with stat training priorities

## Common SP Mistakes

### Mistakes to Avoid

1. **Learning too many skills early** → SP shortage late game
2. **Buying full price with hints pending** → Wasted SP
3. **Ignoring skill synergies** → Inefficient loadout
4. **Over-investing in one category** → Unbalanced build
5. **Panic buying late game** → Poor skill selection

### Recovery Strategies

- Focus on hinted skills only
- Skip luxury skills
- Prioritize race SP rewards
- Use health room for bonus SP events
- Accept suboptimal loadout and plan better next run
