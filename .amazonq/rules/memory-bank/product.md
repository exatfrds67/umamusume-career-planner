# Product Overview

## Project Purpose
Uma Musume Career Planner is a comprehensive web application designed to help players plan, track, and optimize their character development careers in the Uma Musume game. The application provides data-driven insights, performance analytics, and strategic planning tools to maximize character potential and career outcomes.

## Value Proposition
- **Strategic Career Planning**: Plan optimal career paths for Uma Musume characters with data-driven recommendations
- **Performance Analytics**: Track and analyze character statistics, race performance, and career progression
- **AI-Powered Insights**: Leverage hybrid AI systems (AWS Bedrock, Ollama, MCP) for intelligent recommendations and optimization
- **Comprehensive Reporting**: Generate detailed reports on character performance, strengths, and improvement areas
- **Support Card Management**: Manage and optimize support card selections for training efficiency

## Key Features

### Character Management
- Create and manage multiple Uma Musume characters with detailed profiles
- Track character statistics (speed, stamina, power, guts, wisdom)
- Monitor character growth and development over time
- Visual character cards with images and metadata

### Career Planning & Tracking
- Plan complete career paths with race schedules
- Track career status (active, completed, planned)
- Monitor career efficiency and win rates
- Grade-based performance evaluation (S, A, B, C, D, E, F)
- Career history with detailed analytics

### Performance Analytics
- Comprehensive character reports with statistical breakdowns
- Average stat gains visualization with progress bars
- Strengths and improvement areas identification
- Career comparison and benchmarking
- Win rate and efficiency metrics

### Support Card System
- Extensive support card database with images
- Card rarity levels (SSR, SR, R)
- Card type categorization (Speed, Stamina, Power, Guts, Wisdom, Friend)
- Lazy-loaded image optimization for performance
- OCR-based card upload and recognition

### AI Integration
- **AWS Bedrock**: Claude-based AI agents for strategic recommendations
- **Ollama**: Local LLM integration for offline AI capabilities
- **MCP (Model Context Protocol)**: Multi-agent orchestration system
- **Hybrid AI Dashboard**: Unified interface for AI interactions
- AI-powered career optimization suggestions

### Reporting & Insights
- Character performance reports with visual analytics
- Career history tracking with detailed metrics
- Strengths and weaknesses analysis
- Comparative performance across careers
- Export capabilities for data analysis

## Target Users

### Primary Users
- **Uma Musume Players**: Active game players seeking to optimize character development
- **Competitive Players**: Players focused on achieving top rankings and optimal builds
- **Strategy Enthusiasts**: Users who enjoy planning and optimization challenges

### Use Cases
1. **Career Path Optimization**: Plan the most efficient career progression for specific character goals
2. **Performance Analysis**: Analyze past careers to identify patterns and improvement opportunities
3. **Support Card Selection**: Choose optimal support card combinations for training goals
4. **Progress Tracking**: Monitor long-term character development and achievement milestones
5. **Strategic Planning**: Use AI insights to make data-driven decisions about training and racing

## Technical Highlights
- Modern Laravel 12 framework with PHP 8.2+
- Responsive Tailwind CSS 4 design with dark mode support
- Alpine.js for reactive frontend interactions
- SQLite database for lightweight data management
- Vite-powered asset bundling and hot module replacement
- Comprehensive testing with Pest PHP
- AWS SDK integration for cloud AI services
