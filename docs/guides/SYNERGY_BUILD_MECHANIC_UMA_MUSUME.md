## Overview

Below is a detailed explanation of the Synergy Build mechanic in *Uma Musume: Pretty Derby*.
This refers to strategically combining stats, skills, running style, inheritance traits, and team
composition so that multiple systems reinforce each other during races.

Synergy builds are not a single mechanic coded into the game but rather a meta-strategy emerging
from how the race simulation, skills, and character mechanics interact.

Source: [MuMuplayer](https://www.mumuplayer.com/blog/umamusume-pretty-derby-best-team-build-strategies.html)

## 1. What Synergy Build Means in Umamusume

A synergy build is a character setup where multiple elements align to maximize race performance.

These elements include:

- Running style
- Stats
- Skill triggers
- Race conditions
- Teammates
- Inherited traits

When these elements align, skills trigger more reliably and race phases are optimized.

For example:

- Acceleration skills activate exactly at the final corner
- Stamina recovery triggers before last spurt
- Positioning skills maintain the ideal pack placement

Because races are simulated using AI behavior and physics variables, synergy builds significantly
increase win probability.

Source: [MuMuplayer](https://www.mumuplayer.com/blog/umamusume-pretty-derby-best-team-build-strategies.html)

## 2. Layers of Synergy in the Game

Synergy exists across several gameplay layers.

| Layer | Synergy Target |
| --- | --- |
| Stat synergy | Stats complement the race type |
| Skill synergy | Multiple skills activate in sequence |
| Running style synergy | Skills match the runner's style |
| Character synergy | Teammates cover different roles |
| Inheritance synergy | Inherited skills reinforce strategy |

High-level builds usually combine multiple layers simultaneously.

## 3. Stat Synergy

Stats must match the race distance and running style.

Each stat influences a different part of the race simulation.

| Stat | Synergy Role |
| --- | --- |
| Speed | Determines maximum velocity |
| Stamina | Prevents slowdown before final spurt |
| Power | Acceleration and lane movement |
| Guts | Endurance during the last phase |
| Wit | Skill activation reliability |

A build is considered synergistic when these stats align with race strategy.

### Long-Distance Synergy Build

Typical stat priorities:

```text
Speed  >  Stamina  >  Power  >  Wit
```

Reason:

- Stamina prevents early exhaustion
- Speed dominates final sprint
- Power helps corner acceleration

Balanced stat synergy is required because over-specialization can cause failure in later race phases.

Source: [DTG Reviews](https://www.dtgre.com/2025/07/umamusume-el-condor-pasa-build-guide.html)

## 4. Skill Synergy (Skill Chains)

Skill synergy occurs when multiple skills trigger in a sequence that amplifies race performance.

Typical chain structure:

```text
Mid-race positioning skill
        ->
Corner acceleration
        ->
Final straight speed burst
```

Example combination:

| Skill Type | Role |
| --- | --- |
| Mid-race speed | Maintain position |
| Corner acceleration | Start overtaking |
| Final straight boost | Secure victory |

Many characters are designed so that their unique skill activates at the end of these chains, making
earlier skills support the final burst.

Source: [MuMuplayer](https://www.mumuplayer.com/blog/umamusume-pretty-derby-best-team-build-strategies.html)

## 5. Running Style Synergy

Each runner has a preferred racing style:

- Front Runner
- Pace Chaser
- Late Surger
- End Closer

Synergy builds select skills specifically for that style.

### Front Runner Synergy

Goal: Maintain the lead.

Typical skills:

- Early speed boosts
- Escape skills
- Stamina maintenance

### End Closer Synergy

Goal: Massive final sprint.

Typical skills:

- Overtaking abilities
- Final corner acceleration
- Last-spurt speed skills

If the build uses skills incompatible with the running style, activation conditions may never occur.

Example:

- A back-runner cannot trigger skills that require leading the race

Thus running style alignment is a core part of synergy builds.

## 6. Race Phase Synergy

Races contain distinct phases:

1. Opening
2. Mid-race
3. Final corner
4. Final straight

Effective builds ensure that at least one skill activates in each phase.

Example synergy sequence:

```text
Phase 1: Start boost skill
Phase 2: Pace maintenance skill
Phase 3: Corner acceleration
Phase 4: Final straight speed
```

This prevents performance drop between phases.

## 8. Unique Skill Synergy

Each character has a unique skill that acts as the centerpiece of their build.

Example mechanics:

- Some unique skills activate after overtaking opponents
- Others activate when leading the race
- Others activate during the final corner

A synergy build ensures that other skills help trigger the unique skill conditions.

Example:

- Positioning skills keep the runner in mid-pack
- Overtaking skills allow passing opponents
- Unique skill activates during that pass

Characters like Narita Brian or Symboli Rudolf rely on overtaking triggers, making them ideal for late-surger builds.

Source: [Prydwen](https://www.prydwen.gg/umamusume/characters/symboli-rudolf/)

## 9. Character Synergy (Duo Builds)

Certain characters perform best when paired with others.

Example:

- A front runner sets race pace
- A closer benefits from the fast race speed

Example duo synergy:

- Daiwa Scarlet (front runner)

## 10. Debuff and Control Synergy

Some builds focus on hindering opponents rather than pure speed.

Example: stamina debuffer builds.

Mechanics:

- Skills drain stamina from nearby opponents
- Teammates exploit the weakened competition

Typical synergy:

```text
Debuffer (mid-pack)
      +
Closer (final sprint)
```

The debuffer exhausts rivals while the closer finishes the race.

Source: [SportsRant](https://sportsrant.indiatimes.com/gaming/umamusume-pretty-derby-gemini-cup-

## 11. Environmental Synergy

Some skills only activate under specific conditions.

Examples:

- Weather
- Track direction
- Race location

Green skills provide bonuses under these conditions.

Example combinations:

- Right-Handed track bonus
- Standard distance bonus

Combining several of these can produce small but reliable stat boosts.

Source: [Prydwen](https://www.prydwen.gg/umamusume/characters/symboli-rudolf/)

## 12. Inheritance Synergy

Inherited traits can also reinforce a build.

Examples:

- Inherited unique skill hint
- Inherited stamina recovery
- Inherited acceleration skill

Players often select parents whose skills complement the trainee's strategy.

Example:

```text
Parent: acceleration skill
Parent: stamina recovery
Child: final sprint skill
```

This produces a more consistent race strategy.

## 14. Why Synergy Builds Matter

Because races are AI-simulated, raw stats alone do not guarantee victory.

Synergy builds improve:

- Skill activation consistency
- Positioning stability
- Stamina efficiency
- Race phase transitions

A well-synergized build can outperform a higher-stat character with poorly matched skills.
