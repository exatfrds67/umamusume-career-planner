## Finding Issues

Use the file names to identify the audit date and subject:
- `YYYY-MM-DD-*` = Audit date format
- `ai-subsystem-*` = AI system audits
- `authorization-*` = Authorization/security audits
- `telescope-horizon-*` = Queue/monitoring audits
- `DIAGRAM_*` = Diagram and documentation audits
- `PATCH_*` = Patch application audits

For consolidated findings, see the latest audit file for your component of interest.
