## Lessons Learned

### Successes

1. **Incremental Approach**: 20-character batches manageable and testable
2. **Milestone Tracking**: Clear progress markers motivated completion
3. **Data Verification**: Cross-referencing sources ensured accuracy
4. **Seeder Design**: Update-friendly design prevented data loss

### Challenges

1. **Character Name Variations**: Some characters have multiple names/costumes
   - Solution: Added alternate costume versions with descriptive names
   - Example: "Daiwa Scarlet (Scarlet Warrior)"

2. **Data Source Consistency**: Different sources had slight variations
   - Solution: Prioritized official game data
   - Cross-referenced multiple sources for verification

3. **Duplicate Detection**: Some characters appeared multiple times
   - Solution: Seeder checks for existing characters before creating
   - Updates existing characters with new aptitude data
