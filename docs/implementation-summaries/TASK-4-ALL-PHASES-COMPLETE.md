### Training Optimization

**Formula**: `Final Stat Gain = Base Training Gain × Growth Rate + Factor Bonuses`

#### Example: Silence Suzuka Speed Training

- Base Training Gain: 20 points
- Speed Growth Rate: 1.2x
- Speed Factor Bonus: +12 (2★ Blue Factor)
- Final Stat Gain: (20 × 1.2) + 12 = 24 + 12 = 36 points

### Race Performance

**Formula**: `Race Performance = Base Stats + Current Stats + Aptitude Modifier + Factor Bonuses`

#### Example: Silence Suzuka Mile Race

- Base Speed: 60
- Current Speed: 800
- Mile Aptitude: S (1.2x modifier)
- Speed Factor Bonus: +12
- Effective Speed: (60 + 800) × 1.2 + 12 = 1,032 + 12 = 1,044

## Lessons Learned

### Successes

1. **Incremental Approach**: Breaking into 4 phases made implementation manageable
2. **Test-Driven Development**: Caught issues early with comprehensive tests
3. **Comprehensive Documentation**: Easy to track progress and understand system
4. **Parallel Development**: Could work on multiple phases simultaneously
5. **Factory States**: Made testing much easier
6. **Specialization-Based Approach**: Efficient character categorization
7. **Reasonable Ranges**: Good differentiation without extremes
8. **Default Fallback**: Unknown characters get balanced values automatically

### Challenges

1. **Character Name Matching**: Some names don't match API exactly
   - Solution: Verify character names before adding

2. **Data Source Consistency**: Different sources have variations
   - Solution: Cross-reference multiple sources for validation

3. **Column Name Confusion**: `name_en` vs `name` mismatch
   - Solution: Maintain up-to-date schema documentation

4. **Enum Casting**: Star level cast as integer instead of string
   - Solution: Verify casts match column types

5. **Balancing**: Ensuring no character is too weak or too strong
   - Solution: Total stats kept in reasonable ranges
