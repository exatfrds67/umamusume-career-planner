## How to Use Bedrock

### Direct Access
```php
$bedrock = app(\App\Services\AI\BedrockService::class);
$response = $bedrock->generate('Your prompt', [], 'claude-3-5-sonnet');
```

### Via Hybrid Service (Recommended)
```php
$hybrid = app(\App\Services\AI\HybridAIService::class);
$response = $hybrid->processRequest('Your prompt', $context);
// Automatically uses Ollama for simple queries, Bedrock for complex ones
```
